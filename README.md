# ЛР 1. Вариант 5 — Музыкальный онлайн-сервис

Боковиков Азат Тимурович, группа ИДБ-25-12.
ООП в Python, обработка исключений, хранение данных в JSON и XML.

## Запуск

Откройте папку проекта в редакторе или терминале и выполните:

```powershell
py main.py
```

При запуске автоматически загружается `data/data.json`. Пути к данным определяются относительно main.py, поэтому
можно запускать и из другой папки.

## Меню

1 — показать все записи выбранного типа; 
2 — показать одну по ID;
3 — добавить;
4 — изменить;
5 — удалить;
6 — сохранить JSON;
7 — загрузить JSON;
8 — сохранить XML;
9 — загрузить XML;
0 — выйти.

При изменении Enter оставляет прежнее значение. ID назначается автоматически.
Связи вводятся как ID существующих записей. До создания трека должны существовать его альбом и жанр, до создания альбома — исполнитель.

Сохранение ручное: перед выходом используйте пункт 6 или 8. Команды записи
перезаписывают `data/data.json` или `data/data.xml`. Загрузка полностью заменяет
данные в памяти; при ошибке загрузки текущие данные сохраняются.

## Объектная модель и ограничения

Artist — исполнитель, Genre — жанр, Album — альбом, Track — трек,
User — пользователь, Playlist — плейлист, PlaylistItem — трек в плейлисте,
Plan — тариф, Subscription — подписка, Favorite — избранное,
Listening — событие прослушивания.

Сервис учитывает данные, не воспроизводит звук и не принимает платежи.
Один альбом принадлежит одному исполнителю; трек — одному альбому и жанру.
Цена тарифа указана в целых рублях за месяц. Подписка пользователя одна.
Записи истории добавляются вручную. Используемые объекты нельзя удалять,
пока не удалены или не изменены зависимые записи.
